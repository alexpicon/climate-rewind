# Build log

These two files are the working record of how Climate Rewind was built at ForgeHacks 2026 (Oct 7 to 10). They are kept as they were written, for anyone who wants to check the work. Neither is needed to run or use the app.

- [`NOVA-REPORT.md`](NOVA-REPORT.md) is the build log. The web engineer (an AI agent) wrote one section per round: what was built, which checks ran, what was flagged. Later rounds fix what the audits found. The newest round is at the bottom.
- [`REVIEW-vera-2026-10-08.md`](REVIEW-vera-2026-10-08.md) is the first QA audit, by a separate AI reviewer who did not write the code. Each finding is marked **Fixed** with the round that fixed it. The fix evidence is in `NOVA-REPORT.md`.

The audit and the fixes were made by AI agents working under the project's rules (`AGENTS.md`); the founder reviewed and committed every change. Numbers and file names in these logs are as of the day they were written. The README describes the app as it is now.
